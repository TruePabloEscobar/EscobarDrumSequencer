# Escobar Drum Sequencer (EDS Drums)

Drum sampler and step sequencer VST3 for fast pattern creation, per-step dynamics and MIDI export.

**Platform:** Windows x64  
**Format:** VST3  
**Author:** [Pablo Escobar](https://pabloescobardj.web.app/)

[Download the Windows installer EXE](./EscobarDrumSequencer-Setup.exe)

[Download the VST3 ZIP for manual installation](https://github.com/TruePabloEscobar/EscobarDrumSequencer/releases/download/v0.8.3/EscobarDrumSequencer-Windows-v0.8.3.zip)

[View release notes](https://github.com/TruePabloEscobar/EscobarDrumSequencer/releases/latest)

Close your DAW before installing or replacing the plugin. The installer copies the VST3 into the Windows VST3 directory you choose and adds an uninstall entry. For manual installation, extract the ZIP and copy the complete `.vst3` folder into your VST3 plugins directory. Keep the same installation path when updating existing projects and rescan plugins in your DAW.

This repository provides release downloads and the stable update manifest.
